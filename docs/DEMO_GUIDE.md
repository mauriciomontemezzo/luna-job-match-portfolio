# LUNA Job Match — Portfolio Demo Guide

## Purpose

Demonstrate a functional local prototype
of LUNA Job Match to technical recruiters
and potential employers.

The demo emphasizes full-stack development,
workflow automation, explainable matching,
testing, and engineering decisions.

## Demo Environment

- Next.js development server
- Local application URL:
  http://localhost:3000/analisar
- Required n8n workflows configured locally
- Synthetic resume and profile information
- No real applicant personal information

Core API routes are restricted outside
development mode.

This is not a public production deployment.

## Suggested Narration

"LUNA Job Match is an experimental
full-stack application I developed
to explore explainable job matching
and workflow automation.

It combines a Next.js frontend,
TypeScript assessment modules,
external n8n workflows, and Excel
export functionality.

The goal is not to predict hiring
outcomes, but to make job-search
results easier to review and explain.

I also focused on regression testing,
API validation, incremental version
control, and documenting the system's
current limitations."

## Privacy Checklist

Before recording or taking screenshots:

- Use a fictional resume
- Remove real phone numbers and emails
- Do not expose personal identifiers
- Do not show environment variables
- Do not show n8n credentials or tokens
- Avoid browser tabs containing private data
- Avoid showing local filesystem paths
- Verify exported files contain demo data
- Do not present real employer vacancies
  as fictional if they came from live search
- Do not publish sensitive browser logs

## Known Limitations

- Functional local prototype
- External automation setup required
- Production API restrictions remain active
- No completed multi-user deployment
- No production authentication system
- Matching assessments are experimental
- Hiring probability is not calculated

Keep the demonstration focused on
a single end-to-end user journey.

Explain each technical feature briefly
without revealing credentials,
private applicant information,
or internal service URLs.

Do not claim the system is ready
for unrestricted public use.
